## About Me

I have spent more than 25 years in engineering project management, especially in large infrastructure and supervision-related work.

In recent years, I have been exploring how AI agents, scripts, templates, and structured workflows can improve engineering documentation, project coordination, review processes, and knowledge reuse.

This GitHub profile is a place where I organize that exploration:

- turning real engineering workflows into reusable AI-assisted skills
- converting repeated document tasks into structured templates and scripts
- preserving professional judgment, source fidelity, and review boundaries
- sharing anonymized examples that are safe to publish

## What I Care About

- **Engineering context**: AI tools should respect real project constraints, responsibility boundaries, and review procedures.
- **Document quality**: reports, minutes, forms, and review records should be structured, traceable, and easy to check.
- **Reusable workflows**: a useful AI workflow should be repeatable, configurable, and safe to adapt.
- **Anonymization**: public examples should keep the working method while removing project-sensitive information.
- **Practical learning**: small tools and workflows are valuable when they solve repeated real work.
